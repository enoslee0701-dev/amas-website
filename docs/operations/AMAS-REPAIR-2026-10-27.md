## 已实现

### 财务

- 撤销 finance 角色读取完整申请表的专用策略；改为有明确字段投影的人员 RPC，仅提供身份、姓名、班次及财务汇总。财务角色不能因此获得申请人联系方式、表单或学籍信息。
- 财务读取、记账、作废统一验证有效角色与现有 MFA 开关。保持当前开关设置，不擅自开启全站 MFA。
- 记账及作废改为数据库事务 RPC；绑定当前操作者、唯一请求 ID、规范化载荷、回执与审计。同 ID 同操作可安全重试，换载荷或换操作者会冲突；批量要么全部成功，要么不写入。
- 网络中断或超时后保留待核实操作与原请求 ID，页面可查询/重试上次操作；不将“没收到响应”当作“没有记账”。成功后清空金额，阻止快速重复登记。
- 明细采用复合游标与分页；汇总由数据库对全部记录计算；CSV 导出遍历全部页面，增加公式注入防护。测试覆盖超过 1,000 条明细及相同时间戳的分页。
- 原有财务记录不迁移、不删除。新增请求关联不可变，防止作废时改写幂等身份。

### 账号、权限及邀请

- 5 个特权 Edge 入口过滤过期角色；5 个入口拒绝 null、数组、数字等非对象请求，避免 500。
- 邀请创建与审计在一个数据库事务内完成，RPC 使用调用者身份重新校验有效管理员角色和 MFA。
- finance 默认进入财务页，content_admin 默认进入公告页；多个行政角色合并为一个工作空间，导航按权限展示。
- 公告人员获得公告/站点设置和班次公开状态的最小权限；不能编辑教务进度。
- Edge SDK 固定版本并加入依赖锁；8 个入口进行类型检查及本地真实 HTTP 处理器测试。

### 网站与兼容性

- 延迟返回的站点公告刷新不再取消正在处理的资源下载或 AI 回复；专项测试同时检查正常完成与语言切换取消行为。
- 课程筛选按钮补足 44px 点击区域，课程总数改为 68。
- 浏览器 SDK 保持本地加载，固定构建工具将上游包语法降至项目 ES2020 门槛，保存来源及产物哈希。

## 自动化整顿

新增 `node scripts/test-all.mjs`，统一发现测试、分层运行、保存逐项日志和退出码。缺环境、超时或失败均不会标成通过。新增 CI 配置，执行单元/静态、隔离 SQL、Edge 类型与 HTTP、关键浏览器流程；本轮未在 GitHub 上实际运行该工作流。

SQL 每份用例都在全新临时 PostgreSQL 内装载所有迁移，使用合成账号并在用例内回滚；不使用真实账号或线上数据。测试服务器隔离开发者本地及发布配置，明确模拟需要的后端响应。

更新失效测试时保留行为判据：课程搜索按已批准的筛选设计验收；SIS 财务用例改走受保护 RPC；课程学分、审核人和生命周期前置数据按现行流程修复；网络与邮件分别计数。下载等待测试改为由请求屏障控制时序。没有将失败整体豁免或放宽权限断言。

`db6_course_contract.sql` 保留原断言，它属于 0026 后旧导入数据快照，不适用于新库或现行 68 门课程。当前验收入口明确不将该历史阶段用例冒充现行验收，改由现行课程迁移一致性、学分闭环及页面筛选检查覆盖。

1. `20261027034733_finance_authorization_and_idempotency.sql`
2. `20261027035443_content_roles_and_hq_program_catalog.sql`
3. `20261027041233_atomic_teacher_invitation.sql`

财务页面依赖新 RPC；迁移又撤销旧页面直接写账权限。应安排短暂维护窗口，先应用迁移，再部署对应 Edge 源码，最后发布网站及缓存版本。中途不要让用户继续使用旧财务页。数据库、Edge、网站应协调发布，并验证新 JWT 调用；不要靠前端回滚恢复已撤销的直接写权限。

明细分页的时间水位用于限制新增记录范围，不是跨多个 HTTP 请求的数据库事务快照；并发作废、更正及尚未提交事务下的一致性对账仍需专门验收。

本次没有真实账号端到端登录、真实邮件、真实 MFA 绑定、生产并发压测，以及 Safari/Firefox/旧浏览器设备实测。合成 JWT 与临时数据库证明的是本地授权边界和处理器契约，不能证明 GoTrue、邮件服务、线上配置或真实浏览器环境。
